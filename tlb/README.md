# Отчет

1. ЦЕЛЬ РАБОТЫ

Проверка по вычислению размера TLB по изменению времени доступа к данным

---------------------------------------------------------------------

2. ТЕОРЕТИЧЕСКИЕ СВЕДЕНИЯ

TLB - это аппаратный кэш, предназначенный для хранения соответствий
виртуальных адресов физическим адресам памяти.

При обращении к памяти возможны два случая:
- TLB hit - соответствие найдено в TLB, доступ выполняется быстро;
- TLB miss - соответствие отсутствует, выполняется обход таблицы страниц,
  что существенно увеличивает время доступа.

Современные процессоры обычно имеют:
- L1 dTLB (первый уровень);
- L2 TLB (второй уровень).

При превышении количества активно используемых страниц над ёмкостью
TLB возрастает число промахов (TLB miss), что приводит к резкому росту
задержки доступа к памяти.

---------------------------------------------------------------------

3. МЕТОДИКА ЭКСПЕРИМЕНТА

3.1 Основная идея

При постепенном увеличении количества страниц памяти ожидается:
- Пока число страниц не превышает размер TLB, время доступа остаётся причерно одинаковым.
- После переполнения TLB наблюдается скачкообразное увеличение времени доступа.

По точке изменения времени доступа можно оценить размер TLB.

3.2 Организация доступа к памяти

Использовались следующие параметры:
- Размер страницы: 4096 байт;
- Обращение только к одному байту на каждой странице;
- Случайный порядок обхода страниц;
- Около 50 миллионов обращений для каждого измерения;
- Предварительный прогрев для устранения первичных page fault.

6. АНАЛИЗ РЕЗУЛЬТАТОВ

L1 TLB:
- До 64 страниц время доступа составляет примерно 4.5 нс.
- При 64 страницах наблюдается рост времени доступа примерно на 48% относительно baseline.
- Оценочный размер L1 TLB: 64 записи.

L2 TLB:
- При 512 странице виден рост примерно на 50%
- Оценочный размнр L2 TLB: 512 записей.
---------------------------------------------------------------------

7. ВЫВОД

Размер TLB был определён косвенным методом на основе анализа изменения
времени доступа к памяти при увеличении количества активных страниц.

Полученные оценки:
- L1 TLB = 64;
- L2 TLB = 512.

Экспериментальные результаты соответствуют типичной архитектуре
современных процессоров Intel.
